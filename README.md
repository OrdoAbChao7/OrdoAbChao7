### 🌟 Open Source Contributions

Active open source contributor focused on identifying edge-case bugs, hardening core runtime logic, and contributing regression test suites to upstream ecosystems:

- **[HKUDS / DeepTutor](https://github.com/HKUDS/DeepTutor)**: AI Learning & Tutoring Assistant
  - Fixed an issue where consecutive follow-up answers in multi-turn tutoring were misclassified as forgetting, decoupling immediate error correction from delayed review with state replay regression tests ([#1794](https://github.com/HKUDS/DeepTutor/pull/1794)).
  - Resolved cross-platform process decoding exceptions and false LLM retry triggers caused by numeric request IDs; aligned connectivity health checks with configured token budgets and added fault-injection tests ([#1690](https://github.com/HKUDS/DeepTutor/pull/1690) / [#1694](https://github.com/HKUDS/DeepTutor/pull/1694)).
- **[Draculabo / AntigravityManager](https://github.com/Draculabo/AntigravityManager)**: Multi-Model API Proxy & Gateway
  - Resolved HTTP 413 payload truncation on multimodal and large-context inference by setting a 64 MiB limit specifically for model routing while preserving 1 MiB limits on management endpoints ([#335](https://github.com/Draculabo/AntigravityManager/pull/335)).
- **[HKUDS / LightRAG](https://github.com/HKUDS/LightRAG)**: Improved Zhipu SDK error classification and retry handling, adding HTTP MockTransport request regression tests ([#4154](https://github.com/HKUDS/LightRAG/pull/4154)).
